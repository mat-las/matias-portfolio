# Asset provenance

- `precision-impeller.webp` and `precision-impeller-small.webp`: original AI-generated concept artwork created for this portfolio, then converted to WebP at 1536×1024 and 768×512. Prompt: precision CNC aluminium impeller, curved blades, central bore and cobalt hub, pale blue-grey studio surface, three-quarter view with negative space left. Not a photograph of actual work, CAD, or simulation evidence. The full-resolution source PNG is reproducible from this description only approximately; the delivered WebP is committed in Git.
- `contours.svg`: original mathematical contour diagram. Not a real geographic dataset or a specific Peruvian location.
- `data-study.svg`, `risk-study.svg`: original illustrative technical diagrams using synthetic values. Not numerical or financial results.
- `social-preview.png`: original typographic title card, 1200×630. Uses the same colour and type hierarchy as the site.
- `favicon.svg`: original typographic monogram.
- `matias-cv-preview.pdf`: explicitly labelled sample CV. Generated by `scripts/create-cv.py`; includes no invented employer, institution or employment dates.
- Fonts: Archivo (Omnibus-Type), Source Serif 4 (Adobe), IBM Plex Mono (IBM). SIL Open Font License; source license files copied into docs/licenses. Bundled from Fontsource packages, never fetched from a font CDN at runtime.
- Legacy `public/images/machu-hero.png` remains in Git history and the checkout for preservation but is unused by the redesigned site.

The procedural 3D assembly is authored in `src/components/AssemblyScene.tsx` with no external mesh, texture or geometry dependency. Parameter changes can be reproduced from source.
