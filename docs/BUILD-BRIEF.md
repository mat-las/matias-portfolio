# Portfolio build brief

## Direction: Pacific / Mineral

A mechanical engineer's working atlas: cobalt editorial typography, drawing-paper surfaces, deep navy technical features, restrained copper, stepped composition and fine contour lines. Work leads identity. Engineering is the primary discipline, with technology and finance immediately discoverable.

## Implementation contract

Retain React, TypeScript, Vite and Three.js. Structured project data drives all case studies. Use a single lazy engineering assembly canvas with on-demand rendering, keyboard controls, reduced-motion and static fallbacks. Build Home, Projects, About, Experience/CV and Contact; 12 explicitly illustrative projects; evidence-linked capabilities; quick project summaries; repeatable case studies; downloadable sample CV; route metadata and static SEO output.

## Source-of-truth requirements

Commit all authored source, reusable project instructions, structured content, local assets, dependency lockfile, asset provenance and maintenance documentation. Do not commit credentials, node_modules, generated build output or third-party agent system instructions. Preserve existing Git history. Placeholder results must never be presented as real achievements.

## Validation

Production build and lint; desktop and mobile screenshots; keyboard and filtering checks; direct route checks; reduced motion and no-WebGL checks. Record measured results and known limitations honestly.
